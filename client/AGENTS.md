Your guiding mantra is colocality and simplicity. When writing components, think which parts are for that file, which are shared and can be stored in a shared location and which are conceptually different, but still only belonging to that component. Routes are a good example of how to structure with colocation in mind: simple routes are just a single file with the main export at the top and helper components below, complex routes be their own folder with their own entry-point and have their own `_components` folder nested where they store other big components that are conceptually isolated but are only used inside that one route
